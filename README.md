# IEEE CIS MJCET – Official Website 🌐

The official website of the **IEEE Computational Intelligence Society (CIS) Student Chapter, MJCET**.  
This platform showcases our **activities, events, achievements, team, and initiatives**, and serves as a digital presence for students, collaborators, and the larger IEEE community.

---

## 🚀 About IEEE CIS MJCET

The IEEE CIS Student Chapter at **Muffakham Jah College of Engineering & Technology (MJCET)** focuses on promoting learning and innovation in areas such as:

- Computational Intelligence  
- Machine Learning & AI  
- Cyber Security  
- Emerging Technologies  
- Research & Technical Skill Development  

We aim to create a strong technical culture through **workshops, hackathons, events, publications, and collaborations**.

---

## ✨ Website Features

- 🏠 **Home** – Overview of the chapter and its vision  
- 👥 **Team** – Meet the core team and members  
- 🎯 **Activities & Achievements** – Workshops, hackathons, events, press segments, donation drives, and more  
- 📅 **Events** – Past and upcoming events  
- 📞 **Contact** – Reach out to the chapter  

Additional highlights:
- Smooth animations using **GSAP** and **Framer Motion**
- Horizontal scrolling sections
- Fully responsive design
- Modern UI with Tailwind CSS

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Animations:** GSAP, Framer Motion
- **Routing:** React Router v6
- **Icons:** Lucide React
